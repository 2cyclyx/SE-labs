# 软件工程课程实验

本仓库用于存放《软件工程》课程各次实验的交付物。全部实验围绕同一个项目展开：**活动票务与报名系统**。

## 实验目录

| 实验 | 目录 | 主要内容 |
|---|---|---|
| 实验一 需求分析 | [lab1-需求分析](lab1-需求分析/) | 访谈记录、需求列表 |
| 实验二 软件设计与建模 | [lab2-软件设计与建模](lab2-软件设计与建模/) | UML 设计图、UI 界面原型 |

## 版本标签

| 标签 | 说明 |
|---|---|
| `lab1-ai-draft` | 实验一：AI 第一次生成的完整需求初稿（30 条），未经人工修改 |
| `lab1-final` | 实验一：人工审查后的最终需求（36 条） |

## 项目背景

系统面向文化活动策划机构，覆盖活动创建与审核发布、报名与候补递补、现场扫码核销、名单导出与统计分析的完整流程。详细需求见 [lab1-需求分析/requirements.md](lab1-需求分析/requirements.md)。
